- Briefly summarize The Gaming Room client and their software requirements. Who was the client?

The Gaming Room client was looking to expand their already established gaming platform for their Draw It Or Lose It game, that would allow users to participate in the game on multiple platforms.

- What type of software did they want you to design?

They wanted the game to be based on the current Android application and were seeking help with environment setup and streamlining their development. The game needed to be developed using a cross-platform approach. Each game and team name needs to be unique, with the game only allowing one instance of the game to exist in memory at a time. Each team will had more than one player assigned per team, and the game needed the ability to have multiple or single teams playing per game.

- How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?

A major requirement was to ensure the Draw It or Lose It game is cross-platform. I implemented this by designing the sftware to have a backend/frontend architecture so that the core of the game, such as game logic, database communication, and API requesats, is handled by a backend server while the frontend deals mainly with user interfaces, allowing for easier development on other platforms. It is important to consider the user's needs when designing because if the user is not happy with the final product, they will not remain users.
